# 色彩基础与皮卡丘配色搭配

## 教学目标
1. 了解色彩三要素（色相、饱和度、明度）的概念
2. 学会调整颜色的色相、饱和度、明度，优化皮卡丘配色
3. 掌握颜色调整工具（如色相 / 饱和度、亮度 / 对比度）的使用

## 教学过程

1. 色彩知识讲解：通过图片对比，讲解色相、饱和度、明度的概念及对色彩效果的影响，分析皮卡丘经典配色的色彩三要素特点
2. 工具演示：演示色相 / 饱和度、亮度 / 对比度等颜色调整工具的使用方法，指导学生调整皮卡丘的颜色，使其更加鲜艳、协调
3. 创意尝试：鼓励学生尝试调整皮卡丘的配色，创造出不同风格的皮卡丘（如淡彩色皮卡丘、深色皮卡丘）
4. 学会调整颜色的色相、饱和度、明度，优化皮卡丘配色
3. 掌握颜色调整工具（如色相 / 饱和度、亮度 / 对比度）的使用

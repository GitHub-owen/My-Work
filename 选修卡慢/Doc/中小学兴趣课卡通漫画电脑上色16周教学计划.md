# 中小学兴趣课卡通漫画电脑上色 16 周教学计划

## 一、课程总目标

通过 16 周的系统教学，让中小学学生了解卡通漫画电脑上色的基础原理与常用工具，掌握不同风格卡通角色的上色技巧，能够独立完成指定卡通角色的电脑上色作品，并具备一定的色彩搭配与创意表达能力，激发学生对卡通漫画创作的兴趣，提升艺术审美素养。

## 二、课程对象

中小学学生（具备基础电脑操作能力）

## 三、课程时长

16 周，每周 1 次课，每次课 90 分钟

## 四、教学准备

1. 硬件：电脑（配置满足绘画软件运行需求）、数位板（每人 1 台）、投影仪、音响

2. 软件：Photoshop、SAI（提前安装并调试好）

3. 素材：三个卡通角色（皮卡丘、Hello Kitty、海绵宝宝）的线稿图、参考配色图、上色步骤分解图

4. 其他：教学 PPT、练习作业纸、优秀作品案例集

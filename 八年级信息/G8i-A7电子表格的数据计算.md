# 课题:电子表格的数据计算

## 教学目标 

1.学生掌握电子表格软件的基本操作技能：公式计算、函数计算。
2.学生能够比较获得公式计算和函数计算的相同点和不同点，培养学生比较事物的能力。
3.部分学生能够发现单元格“复制柄”功能在公式计算和函数计算中的应用，培养学生观察事物的能力。

## 重点

公式计算和函数计算的区别

## 难点

1. 单元格复制柄的使用技巧
2. 公式计算和函数计算的应用场景

## 教学过程

### 使用公式计算

样表：家庭公用事业费支出表

1. 数据格式设置

- 完成"单价"列输入
- 设置数字格式(格式→单元格→数字)

2. 公式计算基础

- 计算单月水费总价(消耗量×单价)
- 引导学生发现手工计算多个费用耗时较长

>设计思路：通过让学生先手工计算单月水费，体验手工计算的繁琐性，从而引发学生对更高效计算方法的需求。

3. 使用公式计算

- 示例:水费计算 F3=E3*D3
- 学生练习计算其他费用
注意:
- 输入"="开始
- 正确引用单元格
- 回车确认

>设计思路：通过简单的水费计算示例,让学生掌握公式计算的基本步骤和规则。先由教师演示标准操作流程,再让学生独立练习其他费用计算,加深对公式计算方法的理解和运用。注意事项的设置帮助学生避免常见错误,培养规范操作习惯。

4. 使用复制柄

- 演示复制柄快速计算
- 对比手工计算效率
- 强调首个公式准确性

练习:完成test4-2-3.xls中"总价"计算

### 使用函数计算

1. 引入函数概念

- 复习公式法计算
- 以72条记录计算为例,展示公式法效率低下
- 引出函数是预设好的计算公式

2. 函数使用方法

- 选择目标单元格
- 选择函数名
- 选择数据源范围
- 演示SUM函数使用

3. 常用函数练习

- SUM求和函数
- AVERAGE求平均值
- MAX求最大值
- MIN求最小值

4. 实践练习

- 完成test4-2-9练习
- 完成复习题
- 对比公式法和函数法

## 教学随笔

公式计算与函数应用：学生学习Excel公式时兴趣浓厚，但存在几个常见问题：忘记输入"="号；不准确引用单元格，常直接输入数字；复制柄使用不熟练，偶尔误删数据。函数学习中的困难包括：混淆SUM和AVERAGE函数用途；数据范围选择不当，包含空白单元格；函数参数理解不深。改进措施：结合生活实例讲解函数应用；展示错误案例引导学生自主发现问题；设计难度递进的练习，满足不同学习水平需求。

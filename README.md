# 初中信息技术教学备课资料库

这是一个用于管理初中信息技术课程教学备课资料的仓库，主要包含七年级和八年级的信息技术课程教案。通过 Git 版本控制系统来追踪和管理教案修改，便于长期维护和教学经验积累。

## 课程概览

### 七年级课程 (G7i)
主要围绕多媒体演示文稿（PPT）展开，包含三个核心主题：
- 红色之旅
- 机器人与我们的生活
- 科技创造未来

### 八年级课程 (G8i)
聚焦电子表格（Excel）应用，包含三个实践活动：
- 数码相机性能比较
- 家庭公用事业费支出统计
- 学校运动会统计

## 教案格式说明

每个教案文件(.ini)包含以下核心内容：
- 教学目标：课程具体目标
- 重点难点：教学重点和难点分析
- 教学准备：课前准备工作
- 教学过程：详细教学步骤
- 教学随笔：课后反思和经验总结

## 版本管理说明

### 命名规范
- 年级：`G[年级数字]i`（如：G7i）
- 课程：`[单元号][课序号]-[课程名称]`（如：B1-演示文稿的准备.ini）

### 版本控制策略
- 每学期创建新的 tag（如：2024-spring）
- 重大更新创建新分支
- commit 信息需包含具体更新内容

## 使用指南

1. 克隆仓库：
```bash
git clone [仓库地址]
```

2. 日常更新：
```bash
git add .
git commit -m "更新说明：[具体更新内容]"
git push
```

3. 创建学期标签：
```bash
git tag 2024-spring
git push origin 2024-spring
```

## 注意事项

1. 文件更新注意事项：
   - 保持教案格式统一
   - 及时记录教学反思
   - 定期更新重点学生情况

2. 隐私保护：
   - 学生姓名使用化名
   - 不上传具体考试成绩
   - 不包含个人隐私信息
